path Parameters
patientId
required
integer <int32>

The unique ID of the patient.

query Parameters
status
string
Default: "allowed"

Optional query parameter to filter sessions: allowed - sessions that match the patient's total score level. not-allowed - sessions above the patient's total score level. If not specified, all sessions for the patient will be returned.
